# 🏨 Hotel Booking Analytics Dashboard

An interactive **Hotel Booking Analysis & Dashboard** built using Microsoft Excel, PivotTables, PivotCharts, Slicers, KPIs, and VBA.

---

## 📌 Project Overview

This project focuses on analyzing hotel booking data to understand booking patterns, revenue performance, customer segments, reservation status, hotel branches, cities, and market segments.

The project transforms raw hotel booking data into meaningful business insights through Excel-based data analysis and an interactive dashboard.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze hotel booking data
- Track important business KPIs
- Analyze revenue and booking performance
- Compare sales across cities and hotel branches
- Understand customer types
- Analyze reservation status and cancellations
- Compare different market segments
- Build an interactive and visually appealing Excel dashboard

---

## 📊 Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

- 💰 **Total Revenue**
- 🏨 **Total Bookings**
- ❌ **Cancellation Rate**
- 💵 **Average ADR (Average Daily Rate)**

Example dashboard metrics:

| KPI | Value |

## 📂 Workbook Structure

The Excel workbook contains multiple sheets for data analysis, visualization, and dashboard development.

Key sheets include:

- `hotel_bookings_updated_2024` – Hotel booking dataset
- `Analysis` – Analytical calculations
- `Column Chart` – Column chart analysis
- `Area chart` – Area chart analysis
- `Line chart` – Trend analysis
- `Pie chart(Channel)` – Booking channel analysis
- `Doughnut chart(Deposit)` – Deposit type analysis
- `pie chart(customer Type)` – Customer type analysis
- `Scatter chart` – Relationship analysis
- `Doughnut Chart(Reservation)` – Reservation status analysis
- `slicer` – Interactive filtering
- `Dashboard` – Final interactive dashboard

## 🚀 How to Use

1. Download the `.xlsm` file from this repository.
2. Open the workbook using **Microsoft Excel**.
3. Enable macros/content if prompted and if you trust the workbook.
4. Navigate to the **Dashboard** sheet.
5. Use the available slicers to filter the data.
6. Explore the KPIs and charts to analyze hotel booking performance.

> **Note:** Microsoft Excel is recommended for the complete interactive experience because this project uses a macro-enabled `.xlsm` workbook.
